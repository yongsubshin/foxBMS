# 그랜저 하이브리드 (HG HEV) 2016년
## Battery Management System (BMS) 진단코드 목록

본 문서는 **현대 그랜저 하이브리드(HG HEV) 2016년식**의  
정비매뉴얼 DTC 메뉴얼 기준 **BMS(배터리 제어) 관련 진단코드(DTC)** 를 텍스트로 정리한 자료입니다.

---

### 참고
- 본 목록은 **정비매뉴얼 DTC 메뉴얼 화면 기준**으로 정리된 텍스트 자료입니다.
- 실제 차량 트림, ECU 버전, 소프트웨어 업데이트에 따라 일부 코드 차이가 있을 수 있습니다.
