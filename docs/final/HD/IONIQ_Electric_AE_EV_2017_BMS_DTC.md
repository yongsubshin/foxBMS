# 아이오닉 일렉트릭 (AE EV) – 배터리 제어(BMS) DTC 목록 (2017)

본 문서는 현대자동차 **정비매뉴얼 > DTC 매뉴얼** 화면 기준으로  
**아이오닉 일렉트릭 (AE EV) 2017년식 – Battery Management System(BMS)**의

## Battery Management System (배터리 제어)

### 1. 인터락 / 절연 / 냉각
- **P0A0D** : 고전압 배터리 세이프티 플러그 미장착  
- **P0A7E** : 고전압 배터리 과온  
- **P0A81** : 고전압 배터리 팩 냉각 팬1 라인 단선  
- **P0A82** : 고전압 배터리 팩 냉각 팬1 성능 이상  
- **P0AA6** : 고전압 부품 절연파괴  

### 2. 온도 / 전류 센서
- **P0A9D** : 고전압 배터리 1번 온도센서 접지 단락  
- **P0A9E** : 고전압 배터리 1번 온도센서 전원선 단락 또는 단선  
- **P0AAE** : 고전압 배터리 1번 흡기 온도센서 접지 단락  
- **P0AAF** : 고전압 배터리 1번 흡기 온도센서 전원선 단락 또는 단선  
- **P0AC0** : 고전압 배터리 전류센서 성능 이상  
- **P0AC1** : 고전압 배터리 전류센서 단선 또는 접지 단락  
- **P0AC2** : 고전압 배터리 전류센서 전원선 단락  
- **P0AC7** : 고전압 배터리 2번 온도센서 접지 단락  
- **P0AC8** : 고전압 배터리 2번 온도센서 전원선 단락 또는 단선  
- **P0ACC** : 고전압 배터리 3번 온도센서 접지 단락  
- **P0ACD** : 고전압 배터리 3번 온도센서 전원선 단락 또는 단선  

### 3. 메인 / 프리차지 릴레이
- **P0ADB** : 고전압 배터리 메인(+) 릴레이 제어회로 이상  
- **P0ADF** : 고전압 배터리 메인(-) 릴레이 제어회로 이상  
- **P0AE6** : 고전압 배터리 프리차지 릴레이 제어회로 이상  

### 4. 모듈 전압 센싱
- **P0B3B** : 고전압 배터리 1번 모듈 전압센싱부 이상  
- **P0B40** : 고전압 배터리 2번 모듈 전압센싱부 이상  
- **P0B45** : 고전압 배터리 3번 모듈 전압센싱부 이상  
- **P0B4A** : 고전압 배터리 4번 모듈 전압센싱부 이상  
- **P0B4F** : 고전압 배터리 5번 모듈 전압센싱부 이상  
- **P0B54** : 고전압 배터리 6번 모듈 전압센싱부 이상  
- **P0B59** : 고전압 배터리 7번 모듈 전압센싱부 이상  
- **P0B5E** : 고전압 배터리 8번 모듈 전압센싱부 이상  
- **P0B63** : 고전압 배터리 9번 모듈 전압센싱부 이상  
- **P0B68** : 고전압 배터리 10번 모듈 전압센싱부 이상  

### 5. 전압 / 셀 상태
- **P0DE** : 고전압 배터리 저전압  
- **P0E7** : 고전압 배터리 과전압  
- **P1B96** : 고전압 배터리 셀 전압 편차  
- **P1B97** : 고전압 배터리 온도 편차  

### 6. 히터 / 급속충전
- **P1B80** : 고전압 배터리 1번 히터 온도센서 전원선 단락 또는 단선  
- **P1B81** : 고전압 배터리 1번 히터 온도센서 접지 단락  
- **P1B82** : 고전압 배터리 2번 히터 온도센서 전원선 단락 또는 단선  
- **P1B83** : 고전압 배터리 2번 히터 온도센서 접지 단락  
- **P1BA2** : 급속충전용 파일럿(PD) 라인 연결 실패  
- **P1BA4** : 급속충전 릴레이 용착  

### 7. 보호회로 / 통신
- **P1BA7** : 배터리 과충전 보호 회로 활성화  
- **P1BBA** : 고전압 배터리 과충전 차단 회로 활성화  
- **P1BBC** : 과충전 보호 전원회로 이상  
- **P1BBD** : 고전압 배터리 과충전 차단 전원회로 이상  
- **U0001** : CAN 통신 이상 (P-CAN)  
- **U0110** : CAN 통신 회로 – MCU 응답 지연  
- **U019B** : CAN 통신 회로 – OBC 응답 지연  
- **U0293** : CAN 통신 회로 – HCU 응답 지연
