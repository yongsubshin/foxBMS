## Battery Management System (배터리 제어)

### 1. 냉각 / 인터락 / 절연
- **P00B11** : 라디에이터 출구 냉각수 온도센서 접지 단락  
- **P00B12** : 라디에이터 출구 냉각수 온도센서 전원선 단락 또는 단선  
- **P0A0A12** : 고전압 배터리 세이프티 플러그 미장착  
- **P0A7E00** : 고전압 배터리 과온  
- **P0AA600** : 고전압 부품 절연파괴  
- **P0AA700** : 고전압 절연저항 측정라인 이상  

### 2. 전류 센서 이상
- **P0ABF01** : 고전압 배터리 전류센서 성능 이상  
- **P0ABF11** : 고전압 배터리 전류센서 단선 또는 접지 단락  
- **P0ABF12** : 고전압 배터리 전류센서 전원선 단락  

### 3. 온도 센서 이상
- **P0A9B11** : 고전압 배터리 1번 온도센서 접지 단락  
- **P0A9B12** : 고전압 배터리 1번 온도센서 전원선 단락 또는 단선  
- **P0AC511** : 고전압 배터리 2번 온도센서 접지 단락  
- **P0AC512** : 고전압 배터리 2번 온도센서 전원선 단락 또는 단선  
- **P0ACA11** : 고전압 배터리 3번 온도센서 접지 단락  
- **P0ACA12** : 고전압 배터리 3번 온도센서 전원선 단락 또는 단선  
- **P0AE811** : 고전압 배터리 4번 온도센서 접지 단락  
- **P0AE812** : 고전압 배터리 4번 온도센서 전원선 단락 또는 단선  

### 4. 모듈 전압 센싱부 이상
- **P0B3B00** : 고전압 배터리 1번 모듈 전압센싱부 이상  
- **P0B4000** : 고전압 배터리 2번 모듈 전압센싱부 이상  
- **P0B4500** : 고전압 배터리 3번 모듈 전압센싱부 이상  
- **P0B4A00** : 고전압 배터리 4번 모듈 전압센싱부 이상  
- **P0B4F00** : 고전압 배터리 5번 모듈 전압센싱부 이상  
- **P0B5400** : 고전압 배터리 6번 모듈 전압센싱부 이상  
- **P0B5900** : 고전압 배터리 7번 모듈 전압센싱부 이상  
- **P0B5E00** : 고전압 배터리 8번 모듈 전압센싱부 이상  

### 5. 냉각수 / 펌프 / 밸브
- **P0C4211** : 고전압 배터리 1번 냉각수 온도센서 접지 단락  
- **P0C4212** : 고전압 배터리 1번 냉각수 온도센서 전원선 단락 또는 단선  
- **P0C4792** : 배터리측 EWP 펌프 성능 이상  
- **P0CD7F** : 고전압 배터리 1번 냉각수 밸브(배터리측) 성능 이상  

### 6. 배터리 전압 이상
- **P0DE600** : 고전압 배터리 저전압  
- **P0DE700** : 고전압 배터리 과전압  

### 7. 배터리 비정상 거동 감지
- **P1AA700** : 셀 전압 편차  
- **P1AA800** : 절연 고장  
- **P1AA900** : 셀 전압 변화  
- **P1AAA00** : CV 구간 전압 편차  
- **P1AAB00** : 배터리 과온  
- **P1AAC00** : 배터리 과전압  
- **P1AAD00** : 배터리 저전압  
- **P1AAE00** : 배터리 온도 편차  
- **P1AAF00** : MAVD  
- **P1AB000** : RDV  

### 8. 릴레이 / 히터 / 보호회로
- **P1B7600** : 고전압 배터리 릴레이 용착  
- **P1B8000** : 고전압 배터리 히터 온도센서 전원선 단락 또는 단선  
- **P1B8100** : 고전압 배터리 히터 온도센서 접지 단락  
- **P1BA800** : 히터 릴레이 용착  
- **P1BBA00** : 고전압 배터리 과충전 차단회로 활성화  
- **P1BBD00** : 고전압 배터리 과충전 차단 전원회로 이상  

### 9. PRA 버스바 / 냉각수 센서
- **P1BC600** : PRA 버스바 온도센서 접지 단락  
- **P1BC700** : PRA 버스바 온도센서 전원선 단락 또는 단선  
- **P1BD000** : PRA 버스바 온도 과온  
- **P1BD100** : PRA 버스바 온도 과온 Level2  
- **P1BD400** : 배터리 냉각수 수위 초과  
- **P1BD500** : 배터리 냉각수 과다 검출
