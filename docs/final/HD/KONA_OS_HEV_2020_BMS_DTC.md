## 주요 점검 사항

### 고전압 배터리 시스템
1. **세이프티 플러그 상태 확인**
   - 미장착 여부 점검
   - 접촉 불량 확인

2. **온도센서 정상 작동 확인**
   - 1번, 2번 온도센서 점검
   - 접지 단락 및 전원선 단락 확인

3. **배터리 모듈 전압센싱 확인**
   - 모듈 1~6번 전압 센싱부 정상 작동 확인

4. **냉각 팬 작동 상태 점검**
   - 냉각 팬1 라인 단선 확인
   - 팬 성능 이상 여부 점검

### 12V 리튬배터리 시스템
1. **전압 및 온도 모니터링**
   - 과전압/과온 상태 확인
   - 전압 결로 이상 점검

2. **전류센서 정상 작동 확인**
   - 센서 단선 및 단락 확인
   - 성능 이상 여부 점검

3. **릴레이 용착 여부 점검**
   - 릴레이 정상 작동 확인

### 통신 시스템
1. **P-CAN 통신 상태 확인**
   - MCU/HCU 송답 지연 점검
   - 통신 이상 확인

2. **H-CAN 통신 상태 확인**
   - MCU/HCU 송답 지연 점검
   - 통신 이상 확인

## 안전 주의사항

⚠️ **고전압 시스템 작업 시 주의사항**
- 고전압 작업 전 반드시 세이프티 플러그 분리
- 절연장갑 및 안전장비 착용 필수
- 정비 매뉴얼에 따른 절차 준수
- 배터리 온도 및 전압 정상 범위 확인
- 고전압 케이블 손상 여부 확인

⚠️ **12V 리튬배터리 작업 시 주의사항**
- 과충전 보호 회로 정상 작동 확인
- 셀 전압 편차 모니터링
- 온도 센서 정상 작동 확인
