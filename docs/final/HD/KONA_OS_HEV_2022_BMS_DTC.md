# 코나 하이브리드(OS HEV) 배터리제어 DTC 목록 (2022)

## 고전압 배터리 / BMS 관련

- **P0A0A12** : 고전압 배터리 세이프티 플러그 미장착
- **P0A7E00** : 고전압 배터리 과온
- **P0A7F00** : 고전압 배터리 열화
- **P0A8113** : 고전압 배터리 팩 냉각 팬 1 라인 단선
- **P0A819F** : 고전압 배터리 팩 냉각 팬 1 성능 이상
- **P0A9B11** : 고전압 배터리 1번 온도센서 접지 단락
- **P0A9B12** : 고전압 배터리 1번 온도센서 전원선 단락 또는 단선
- **P0AA600** : 고전압 부품 절연파괴
- **P0ABF01** : 고전압 배터리 전류센서 성능 이상
- **P0ABF11** : 고전압 배터리 전류센서 단선 또는 접지 단락
- **P0ABF12** : 고전압 배터리 전류센서 전원선 단락
- **P0AC511** : 고전압 배터리 2번 온도센서 접지 단락
- **P0AC512** : 고전압 배터리 2번 온도센서 전원선 단락 또는 단선

## 모듈 / 전압 이상

- **P0B3B00** : 고전압 배터리 1번 모듈 전압센싱부 이상
- **P0B4000** : 고전압 배터리 2번 모듈 전압센싱부 이상
- **P0B4500** : 고전압 배터리 3번 모듈 전압센싱부 이상
- **P0B4A00** : 고전압 배터리 4번 모듈 전압센싱부 이상
- **P0B4F00** : 고전압 배터리 5번 모듈 전압센싱부 이상
- **P0B5400** : 고전압 배터리 6번 모듈 전압센싱부 이상
- **P0C3000** : 고전압 배터리 SOC 과다
- **P0DE600** : 고전압 배터리 저전압
- **P0DE700** : 고전압 배터리 과전압

## 인버터 / 릴레이

- **P1B2500** : 인버터 고전압단과 고전압 배터리 전압 편차
- **P1B7600** : 고전압 배터리 릴레이 용착
- **P1B7700** : 인버터 커패시터 프리차징 실패
- **P1B9600** : 고전압 배터리 셀 전압 편차
- **P1B9700** : 고전압 배터리 온도 편차
- **P1BA700** : 배터리 과충전 보호 회로 활성화

## 12V 리튬 배터리

- **P1BB000** : 12V 리튬배터리 릴레이 용착
- **P1BB200** : 12V 리튬배터리 과전압
- **P1BB300** : 12V 리튬배터리 과온
- **P1BB400** : 12V 리튬배터리 1번 온도센서 접지 단락
- **P1BB500** : 12V 리튬배터리 1번 온도센서 전원선 단락 또는 단선
- **P1BB600** : 12V 리튬배터리 전류센서 단선 또는 접지 단락
- **P1BB700** : 12V 리튬배터리 전류센서 전원선 단락
- **P1BB800** : 12V 리튬배터리 전류센서 성능 이상
- **P1BB900** : 12V 리튬배터리 전압센싱부 이상
- **P1BBB00** : 12V 리튬배터리 셀 전압 편차
- **P1BBC00** : 과충전 보호 전원회로 이상
- **P1BBE00** : 12V 전압 경로 이상

## PRA / CAN 통신

- **P1BC600** : PRA 버스바 온도센서 접지 단락
- **P1BC700** : PRA 버스바 온도센서 전원선 단락 또는 단선
- **P1BC800** : PRA 버스바 온도센서 성능 이상
- **P1BD100** : PRA 버스바 온도 과온 Level 2
- **U000100** : CAN 통신 이상 (P-CAN)
- **U011000** : CAN 통신 회로 - MCU 응답 지연 (P-CAN)
- **U029300** : CAN 통신 회로 - HCU 응답 지연 (P-CAN)
- **U100100** : CAN 통신 이상 (H-CAN)
- **U100400** : CAN 통신 회로 - HCU 응답 지연 (H-CAN)
- **U100500** : CAN 통신 회로 - MCU 응답 지연 (H-CAN)
