## 8. CAN / 통신 진단 코드

- **U000100** : CAN 통신 이상 (P-CAN)
- **U011000** : CAN 통신 회로 – MCU 응답 지연
- **U029300** : CAN 통신 회로 – HCU/VCU 응답 지연
- **U041182** : ECU–MCU 간 통신 데이터 신뢰성 오류
- **U059400** : CAN 통신 회로 – HCU/VCU CRC/AC 오류 (G-CAN)
- **U111800** : 통신 회로 – 고전압 배터리 냉각수 펌프(EWP) 1번 응답 지연
- **U111900** : 통신 회로 – 냉각수 펌프(for DATC) 응답 지연
- **U112800** : 통신 이상 – 고전압 배터리 1번 냉각수 밸브
- **U130E87** : CAN 통신 회로 – 차량 충전 관리 시스템(VCMS) 응답 지연
- **U141582** : CAN 통신 데이터 이상 – VCMS (G-CAN)
