## 1. 냉각수 / 인터락 / 절연 관련

- **P00B111** : 라디에이터 출구 냉각수 온도센서 이상
- **P00B112** : 라디에이터 출구 냉각수 온도센서 이상
- **P0A0A12** : 고전압 시스템 인터락 회로 미체결
- **P0A7E00** : 고전압 배터리 과온
- **P0AA600** : 고전압 부품 절연파괴
- **P0AA700** : 고전압 절연저항 측정라인 이상

## 7. BMS / PRA / CAN 통신

- **P1BBA00** : BMS 과충전 차단회로 활성화
- **P1BBD00** : BMS 과충전 차단회로 전원회로 이상
- **P1BC600** : PRA 버스바 온도센서 접지 단락
- **P1BC700** : PRA 버스바 온도센서 전원선 단락 또는 단선
- **U000100** : CAN 통신 이상 (P-CAN)
- **U011000** : MCU 응답지연
- **U029300** : HCU/VCU 응답지연
- **U041182** : FCU-MCU 간 통신 데이터 신뢰성 오류
- **U059400** : CAN 통신 CRC/AC 오류 (G-CAN)
