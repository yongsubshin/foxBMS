## 코드 분류 요약

### P 코드 (Powertrain - 파워트레인 관련)

| 분류 | 설명 |
|------|------|
| P0Axxx | 고전압 시스템, 배터리 기본 관련 (인터록, 과온, 절연) |
| P0Bxxx | 전압센싱부 관련 (1~10번) |
| P0Cxxx | 온도센서 관련 (5~16번, 냉각수 온도센서) |
| P0DExxx | 배터리 전압 이상 (저전압/과전압) |
| P1Axxx | 에어백 연동, 배터리 비정상 거동 감지 (AVCD, RDV 등) |
| P1Bxxx | 인버터, 릴레이, 히터온도센서, 써멀 이벤트 |
| P1Cxxx | 17~24번 온도센서 관련 |
| P2FExxx | 25~31번 온도센서 관련 |
