| 분류 | 설명 |
|------|------|
| P00Bxxx | 라디에이터 냉각수 온도센서 |
| P0Axxx | 고전압 시스템, 배터리 기본 관련 (인터록, 과온, 절연, 전류센서) |

| P1Axxx | 에어백 연동, 비정상 거동 감지 (AVCD 포함) |
| P1ADxxx | 고급 비정상 거동 감지 (OCV, CCV, RS, MISD, 열폭주, SP-MISD, MISD2) |
| P1Bxxx | 인버터, 릴레이, 히터, BMS 과충전 차단, PRA 버스바, 하부 온도센서, 써멀 이벤트 |
