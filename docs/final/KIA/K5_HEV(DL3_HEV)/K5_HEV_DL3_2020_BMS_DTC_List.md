## 코드 분류 요약

### P 코드 (Powertrain - 파워트레인 관련)

| 분류 | 설명 |
|------|------|
| P0Axxx | 고전압 시스템, 배터리 기본 관련 (세이프티 플러그, 과온, 열화, 냉각팬, 절연, 전류센서) |
| P0Bxxx | 전압센싱부 관련 (1~7번 모듈) |
| P0Cxxx | 배터리 SOC 관련 |
| P0DExxx | 배터리 전압 이상 (저전압/과전압) |
| P1Axxx | 에어백 연동 |
| P1Bxxx | 인버터, 릴레이, 셀 전압/온도 편차, 12V 리튬배터리, BMS 과충전 차단, PRA 버스바 |

### U 코드 (Network Communication - 통신 관련)

| 분류 | 설명 |
|------|------|
| U000100 | CAN 통신 기본 이상 (P-CAN) |
| U011000 | MCU 응답 지연 (P-CAN) |
| U029300 | HCU 응답 지연 (P-CAN) |
| U100100 | CAN 버스 OFF (H-CAN) |
| U100400 | HCU 응답 지연 (H-CAN) |
| U100500 | MCU 응답 지연 (H-CAN) |
