## 코드 분류 요약

### P 코드 (Powertrain - 파워트레인 관련)

| 분류 | 설명 |
|------|------|
| P0Axxx | 고전압 시스템, 배터리 기본 관련 (인터록, 과온, 열화, 냉각팬, 절연, 흡기 온도센서, 전류센서) |
| P0Bxxx | 전압센싱부 관련 (1~9번) |
| P0DExxx | 배터리 전압 이상 (저전압/과전압) |
| P1Axxx | 에어백 연동 |
| P1Bxxx | 인버터, 릴레이, 셀 전압/온도 편차, 과충전 보호 회로 |

### U 코드 (Network Communication - 통신 관련)

| 분류 | 설명 |
|------|------|
| U0001 | CAN 통신 기본 이상 (P-CAN) |
| U0110 | MCU 응답 지연 (P-CAN) |
| U0293 | HCU 응답 지연 (P-CAN) |
| U1001 | CAN 버스 OFF (H-CAN) |
| U1004 | HCU 응답 지연 (H-CAN) |
| U1005 | MCU 응답 지연 (H-CAN) |
