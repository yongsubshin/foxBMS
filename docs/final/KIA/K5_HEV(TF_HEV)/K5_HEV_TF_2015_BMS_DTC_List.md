## 코드 분류 요약

### P 코드 (Powertrain - 파워트레인 관련)

| 분류 | 설명 |
|------|------|
| P0Axxx | 고전압 시스템, 배터리 기본 관련 (안전 플러그, 과온, 성능저하, 절연, 흡기온 센서, 전류센서, 온도센서) |
| P1Axxx | 에어백 연동 |
| P1Bxxx | 보조 배터리, 고전압 경로, 전류센서, 저전압/과전압, 전압센싱, 릴레이, 프리차징, 팬 모듈 |

|------|------|

| U1001 | CAN 버스 OFF (H-CAN) |
