## 코드 분류 요약

### P 코드 (Powertrain - 파워트레인 관련)

| 분류 | 설명 |
|------|------|
| P0Axxx | 고전압 시스템, 배터리 기본 관련 (세이프티 플러그, 과온, 열화, 냉각팬 1/2, 절연, 흡기 온도센서 1/2, 전류센서, 온도센서 1~4) |
| P0Bxxx | 전압센싱부 관련 (1~12번 모듈), 온도센서 5회로 |
| P0Cxxx | 배터리 SOC 관련 |
| P0DExxx | 배터리 전압 이상 (저전압/과전압) |
| P1Axxx | 에어백 연동 |
| P1Bxxx | 인버터, 릴레이, 셀 전압/온도 편차, 과충전 보호/차단 회로 |
