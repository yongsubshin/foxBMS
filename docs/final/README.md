## Quick Start

### View Documentation

Open the main portal in your browser:

```bash
# Linux

# macOS
open docs/final/index.html

# Windows
start docs/final/index.html
```

### Build Documentation

```bash
cd docs/final
./build.sh
```

- **Software Level (SWE.1-SWE.6)**: SW requirements, architecture, design, verification

**Build Sphinx:**
```bash
pip install sphinx sphinx-rtd-theme
cd sphinx && sphinx-build -b html . _build/html
```
