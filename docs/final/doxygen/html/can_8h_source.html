114/**
115 * @brief Checks the data received per CAN.
116 * A receive buffer is used because CAN frames are received in an interrupt routine.
117 * The TMS570LC4357 does not allow nested interrupts, so interrupts are deactivated during receive.
118 * Calls to the database do not work when interrupts are disabled.
119 * Receive callbacks are made within this function: as it is not called during an interrupt routine,
120 * calls to the database can be made.
121 */
122extern void CAN_ReadRxBuffer(void);
