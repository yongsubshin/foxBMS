◆ CRC_REGISTER_SIDE_e

enum CRC_REGISTER_SIDE_e

CRC signature register, low of high part to be used . The register is 64 bit wide but the data is read in 32 bit chunks. This indicates if the low or the high part has to be written.

Computes CRC of data flow.

This function uses the hardware of the MCU. Data must be given in byte chunks.

Parameters
[in]pCrcuint64_t pointer to the calculated CRC
[in]pDatauint8_t pointer to the start of the data flow
[in]lengthInByteslength in bytes of the data flow
Returns
STD_OK if CRC hardware available, STD_NOT_OK otherwise
