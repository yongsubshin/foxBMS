42/**
43 * @file diag_cfg.c
44 * @author foxBMS Team
45 * @date 2019-11-28 (date of creation)
46 * @updated 2025-08-07 (date of last update)
47 * @version v1.10.0
48 * @ingroup ENGINE_CONFIGURATION
49 * @prefix DIAG
50 *
51 * @brief Diagnostic module configuration
52 * @details The configuration of the different diagnosis events defined in
53 * diag_cfg.h is set in the array diag_diagnosisIdConfiguration[],
54 * e.g., initialization errors or runtime errors.
55 *
56 * Every entry of the diag_diagnosisIdConfiguration[] array consists
57 * of
58 * - name of the diagnosis event (defined in diag_cfg.h)
59 * - type of diagnosis event
60 * - diagnosis sensitivity (after how many occurrences event is
61 * counted as error)
62 * - enabling of the recording for diagnosis event
63 * - enabling of the diagnosis event
64 * - callback function for diagnosis event if wished, otherwise
65 * DIAG_dummy_callback
66 *
67 * The system monitoring configuration defined in diag_cfg.h is set in
68 * the array sysm_ch_cfg[]. The system monitoring is at the moment
69 * only used for supervising the cyclic/periodic tasks.
70 *
71 * Every entry of the sysm_ch_cfg[] consists of
72 * - enum of monitored object
73 * - type of monitored object (at the moment only
74 * DIAG_SYSMON_CYCLICTASK is supported)
75 * - maximum delay in [ms] in which the object needs to call the
76 * SYSM_Notify function defined in diag.c
77 * - enabling of the recording for system monitoring
78 * - enabling of the system monitoring for the monitored object
79 * - callback function if system monitoring notices an error if
80 * wished, otherwise SYSM_DummyCallback
81 */
