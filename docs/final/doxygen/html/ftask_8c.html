void FTSK_CreateTaskCyclic100ms ( void *const  pvParameters)
extern

Creation of cyclic 100 ms task.

Task is delayed by a phase as defined in ftsk_taskDefinitionCyclic100ms.phase (in milliseconds). After the phase delay, the cyclic execution starts, the entry time is saved in current_time. After one cycle, the Task is set to sleep until entry time + ftsk_taskDefinitionCyclic100ms.cycleTime (in milliseconds).
