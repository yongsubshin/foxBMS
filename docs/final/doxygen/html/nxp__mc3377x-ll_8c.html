Detailed Description

Low level driver for the NXP MC3377xA.

Author
NXP
Date
2022-07-29 (date of creation) @updated 2025-06-25 (date of last update)
Version
v1.10.0

@prefix N77X

Implements the low level interface for the NXP MC3377xA IC. These functions are consumed by the abstracted, high level driver implemented nxp_mc3377x.c.

Changes made to the original NXP MC3377xA driver:

  • Changed prefix to N77X
  • introduced variable responseIndex and N77X_TX_MIRROR_OFFSET to reflect the message structure better.

#define N77X_MAX_ANSWER_FRAMES   (30u)

Maximum number of groups of registers that can be read, to limit buffer size. Groups can be of size 1 to 4 registers. One frame = header (e.g., register address) + payload (data, 1 to 4 registers)
