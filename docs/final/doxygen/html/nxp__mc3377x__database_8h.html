void N77x_InitializeDatabase ( N77X_STATE_s *  pState)
extern

in the database, initializes the fields related to the N77X driver.

This function loops through all the N77X-related data fields in the database and sets them to 0. It shall be called in the initialization or re-initialization routine of the N77X driver.
