TIMER_create allows to create a new virtual timer.

This function calls intern xTimerCreateStatic to create a new timer instance with the given variables.

Parameters
cpxTimerNamethe name of the timer
uxTimerPeriodInMSthe amount of time it waits before calling the callback function pxCallbackFunction
cuxAutoReloadwhether the timer only fires once or automatically restarts after firing
cpxTimerIDID for our timer. Please use the defines in this header to create a new ID
pxCallbackFunctionthe callback function that gets executed once the timer triggers it
pxTimerBuffera pointer to an StaticTimer_t type used as memory buffer for the timer
Returns
a TimeHandle_t to interact with the timer
