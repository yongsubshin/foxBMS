extern

Extract characters from a string.

  • Extracts up to 8 characters of a String
    • Characters are extracted consecutively
    • If the end of the string is reached the function ends, this is even if the number of requested number of chars wasn't reached
      Parameters
      pExtractedCharacters64-bit variable where characters are written
      pStringString that chars will be extracted from
      stringLengthLength of the string
      startCharFirst char that will be extracted
      numberOfCharsNumber of Chars that will be extracted
