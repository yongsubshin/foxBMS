Safety Limits (MSL/RSL/MOL)

3-tier threshold system

MSL - Maximum Safety Limit

Immediate contactor opening. Most critical safety threshold.

Action: Immediate contactor open + CAN error transmission

RSL - Recommended Safety Limit

Warning level. System can continue but requires attention.

Action: Warning flag + logging

MOL - Maximum Operating Limit

Information level. Normal operating boundary.

Action: Information logging only

Database Flags

  • DATA_BLOCK_MSL_FLAG_s

Open Wire Detection Algorithm

1. Apply Pull-up current → Measure cell voltage (openWirePup)
2. Apply Pull-down current → Measure cell voltage (openWirePdown)
3. Calculate delta: openWireDelta = openWirePup - openWirePdown
4. Compare against threshold:
   - First cell: Pup value is 0 or max → Open wire
   - Last cell: Pdown value is 0 or max → Open wire
   - Middle cells: Delta < -400mV → Open wire
